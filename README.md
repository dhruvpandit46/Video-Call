A lightweight browser-based peer-to-peer video calling application built using **HTML, CSS, JavaScript, WebRTC, and PeerJS**.

The project allows two users to connect directly using unique Peer IDs and supports real-time **video calling, audio communication, and instant messaging** without requiring a traditional backend server.

# ⚡ How It Works

1. Open the application.

2. A unique Peer ID is automatically generated.

3. Share your Peer ID with another user.

4. Enter the other user's Peer ID.

5. Grant camera and microphone permissions.

6. Establish a direct peer-to-peer connection.

7. Start a video call and exchange real-time messages.

No backend server is required for media transmission.
